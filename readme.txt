Lightweight animation and interaction effects for Elementor widgets and containers.

== Description ==

VRED Effects adds lightweight native animation effects to Elementor without external animation libraries.

Main features:

* 23 text animation presets for Elementor Heading widgets.
* Native Web Animations API and IntersectionObserver runtime.
* VRED word, character and responsive line splitting.
* Speed, stagger, delay, intensity, trigger position and playback controls.
* Responsive animation control through Elementor native responsive controls.
* Live effect preview inside the Elementor editor.
* Reduced-motion support.
* Conditional frontend asset loading.
* Self-hosted VRED updater with manual update checks from the WordPress Plugins screen.

== Requirements ==

* WordPress 6.5 or later. Tested up to WordPress 7.1.2.
* PHP 7.4 or later.
* Elementor.

== Installation ==

1. Upload and activate VRED Effects.
2. Edit an Elementor Heading widget.
3. Open Advanced > VRED Effects.
4. Choose an effect and adjust its controls.

== Configuration ==

VRED Effects integrates directly with supported Elementor widgets and keeps its controls inside the Advanced tab, next to Elementor Motion Effects.

Text effects include controls for effect selection, responsive animation state, speed, stagger, delay, intensity, trigger position and playback.

Playback can run once or each time the element enters the viewport.

Frontend assets are loaded only when a VRED effect requires them.

== Updates ==

VRED Effects uses the self-hosted VRED updater. You can force a fresh update check from Plugins > VRED Effects > Check updates.
